## 一、实验目的与要求

- 了解多模态学习（Multimodal Learning）的基本概念，理解图像与文本两种模态如何在同一模型中联合建模。
- 掌握 Image Captioning（图像描述生成）任务的原理：模型以图像为输入，自回归地逐词生成自然语言描述。
- 了解 BLIP（Bootstrapping Language-Image Pre-training）模型的架构：视觉编码器提取图像特征，语言解码器基于图像特征生成文本。
- 学会使用 Hugging Face Transformers 库调用预训练多模态模型，并通过 DeepSeek API 对描述进行丰富扩展和高质量中文翻译。
- 掌握 Beam Search、ITM（Image-Text Matching）图文匹配检索等推理优化技术，提升生成描述的质量。
- 结合 YOLO 目标检测，实现区域级别的细粒度场景描述。
- 能够将推理结果可视化展示，生成带有中英文标注的图片输出。


## 三、实验过程及内容

### 3.1 BLIP 模型架构

BLIP（Salesforce Research, ICML 2022）核心架构：

- **视觉编码器（Vision Encoder）**：基于 ViT-B/16，将 384×384 输入图像切分为 patch，提取视觉特征序列（hidden_size=768）。
- **语言解码器（Language Decoder）**：基于 BERT-base 架构的交叉注意力解码器（12 层 Transformer），以视觉特征为条件自回归生成文本。
- **图文匹配编码器（ITM Encoder）**：通过交叉注意力融合图像与文本特征，输出匹配分数。

### 3.2 单图推理（caption.py）

实现了两种生成模式：

- **无条件生成**：`model.generate(**inputs, max_new_tokens=50)`，模型自由描述。
- **条件生成**：以 "a photo of" 作为 prompt 前缀引导生成。

翻译采用 Helsinki-NLP/opus-mt-en-zh（MarianMT 架构），并使用 matplotlib 生成中英双语的标注图片。

### 3.3 批量可视化主输出（caption_visualize.py）★核心模块

这是本次实验的核心输出脚本，处理流程如下：

**Step 1 — BLIP 多策略描述生成**：

```python
# 尝试多个提示词前缀，择优选取
prompts = ["a detailed photograph of", "a photo of", ""]
for prompt in prompts:
    outputs = blip.generate(
        **inputs,
        max_new_tokens=80, min_length=6,
        num_beams=7, repetition_penalty=1.3,
        length_penalty=1.2, no_repeat_ngram_size=2,
        early_stopping=True,
    )
# 选择长度最长、质量最高的候选
candidates.sort(key=lambda c: len(c.split()), reverse=True)
```

**Step 2 — DeepSeek API 丰富扩展 + 中文翻译**：

```
Prompt:
"原始描述: a woman dancing in a dance studio"

DeepSeek 输出:
ENRICHED: A woman in a flowing white dress moves gracefully across
a sunlit dance studio, her arms extended as she spins near the
mirrored wall, with soft shadows dancing on the wooden floor.
中文翻译: 一位身着飘逸白裙的女子在阳光洒落的舞蹈教室里优雅舞动，
她伸展双臂在镜墙旁旋转，木地板上投下柔和的影子。
```

**Step 3 — 图片标注可视化**：

使用 PIL 在图片顶部叠加半透明黑色背景条，统一白色文字显示三条信息：

- `BLIP: <原始英文描述>`
- `ENRICHED: <DeepSeek 丰富的英文>`
- `中文翻译: <中文翻译>`

字体大小根据图片宽度自适应（24-44px），中英文混合换行智能处理，文字区域最多占图片高度 40%。

### 3.4 Beam Search 优化（caption_beam.py）

将默认的贪婪解码替换为 Beam Search：

```python
outputs = model.generate(
    **inputs, max_new_tokens=50, min_length=3,
    num_beams=10, num_return_sequences=3,
    early_stopping=True,
    output_scores=True, return_dict_in_generate=True,
)
```

每个候选按累积 log 概率排序，过滤过短描述（< 3 词），不足时回退到贪婪解码补充。

### 3.5 ITM 图文匹配检索（caption_retrieval.py）

利用 `Salesforce/blip-itm-base-coco` 模型进行图文匹配打分：

1. Beam Search 生成 5 个候选描述
2. 对每个候选计算 ITM 匹配分数
3. 按分数降序排列，选出最优描述

### 3.6 YOLO + BLIP 区域描述（caption_yolo_region.py）

```python
yolo = YOLO("yolo11n.pt")           # 目标检测
results = yolo(image, conf=0.3)      # 置信度阈值 0.3
for box, cls_id in zip(boxes, classes):
    region = crop_region(image, box) # 裁剪物体区域
    desc = blip_processor.decode(    # BLIP 描述该区域
        blip.generate(**inputs, max_new_tokens=30)[0])
```

检测到的物体包括 person、tv、laptop、keyboard、clock、chair、bottle、tie 等，并为每个区域生成独立描述。

### 3.7 翻译对比（caption_translate_llm.py）

对比 MarianMT（本地模型）与 DeepSeek API（云端大模型）的翻译质量：

```python
# MarianMT: 传统 seq2seq 翻译
zh_mt = marian_tokenizer.decode(marian.generate(**inputs)[0])

# DeepSeek API: 大模型翻译
response = requests.post("https://api.deepseek.com/chat/completions",
    json={"model": "deepseek-chat", "messages": [...], "temperature": 0.1})
```

### 3.8 GPU 批量加速（caption_batch_gpu.py）

通过 PyTorch DataLoader 将多张图片打包为 batch 同时送入模型：


### 4.5 结果分析

- **BLIP 对常见场景描述准确**，能正确识别主要物体及其属性（颜色、动作），但输出偏向简洁（COCO 训练集的固有特点）。
- **DeepSeek API 丰富扩展效果显著**：在保留原始事实内容的前提下，补充了颜色、材质、光影、氛围等细节，英文描述从平均 8 词扩展到 35 词，中文翻译从短句变为完整段落。
- **MarianMT 与 DeepSeek 翻译对比**：MarianMT 输出生硬（如"带着一碗食物"），DeepSeek 输出自然流畅（如"面前放着一碗食物"），差距明显。
- **Beam Search 优化**：增加 num_beams 和 length_penalty 后，候选描述多样性提升，但部分图片仍会出现空描述，需要 min_length 约束和回退机制。
- **ITM 匹配效果良好**：对大多数图片 ITM 分数在 0.85 以上，能有效从多候选中选出最优描述。
- **YOLO 区域描述**：对人物密集场景（教室）检测效果好，但对昏暗场景（舞蹈室）仅检测到 1 人，说明 YOLO 对光照条件敏感。

## 五、实验结论

1. 本实验成功调用 BLIP 多模态预训练模型，实现了从图像到自然语言描述的端到端生成，并结合 DeepSeek API 大模型完成了描述丰富扩展和高质量中文翻译，构建了"视觉理解 + 语言生成 + 翻译输出"的完整流水线。

2. 实验验证了 **BLIP 提取 + 大模型丰富** 的混合架构优势：BLIP 提供准确的视觉事实基础，DeepSeek 补充语境细节和自然表达，两者互补，输出质量远超单独使用任一模型。

3. Beam Search、ITM 图文匹配等推理优化技术有效提升了描述的多样性和准确性，ITM 分数可作为自动质量评估的参考指标。

4. 翻译质量方面，DeepSeek API 相比传统 MarianMT 有质的飞跃，中文表达自然流畅，能正确处理语序、量词、成语等中文特有的语言现象。

5. YOLO + BLIP 的区域描述方案实现了对复杂场景中每个物体的细粒度理解，但受限于 BLIP 对局部区域的描述能力和 YOLO 的检测精度，效果有待提升。

6. 后续改进方向：（1）引入 BLIP-2 或 LLaVA 等更强的多模态大模型；（2）使用 GPU 加速推理（需安装 CUDA 版 PyTorch）；（3）将 YOLO 检测与 BLIP 描述更深度地结合，利用物体空间关系生成结构化场景图。
